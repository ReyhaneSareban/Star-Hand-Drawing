# Star Hand Drawing

A creative drawing app that lets you draw with your hand using a webcam.

### Features
- Draw with your index finger.
- Use random star images as drawing stamps.
- Rotate stars with continuous animation.
- Move drawn shapes using a pinch gesture.
- Clear the screen with a particle explosion.

### Built With
- Python
- OpenCV
- MediaPipe
- NumPy

### Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

### Usage

1. Clone this repository.
2. Install the required libraries.
3. Make sure the `stars` folder is in the project directory.
4. Open `stars.ipynb` and run the code.

Press `Q` to close the application.
